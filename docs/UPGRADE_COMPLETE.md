### Example 2: Customized Settings

```python
from pipeline.master_pipeline import MasterPipeline
from pipeline.presets import PresetLibrary

# Load and customize preset
preset = PresetLibrary.get_preset("youtube_professional")
preset.voice_speed = 1.1
preset.color_grade = "cinematic"
preset.subtitle_style = "karaoke"

# Generate
pipeline = MasterPipeline()
pipeline.generate_video(
    script="Your customized content...",
    avatar_image="photo.jpg",
    preset=preset,
    background_music="music/bg.mp3",
    output_path="custom.mp4"
)
```

### Example 3: Batch Processing

```python
scripts = [
    "Video 1 script...",
    "Video 2 script...",
    "Video 3 script..."
]

for i, script in enumerate(scripts):
    generate_with_preset(
        script=script,
        avatar_image="avatar.jpg",
        preset_name="youtube_professional",
        output_path=f"video_{i+1}.mp4"
    )
```

## 🔧 Troubleshooting

### Dependencies Not Installing?

```bash
# Try installing problematic packages separately
pip install torch torchvision
pip install opencv-python
pip install librosa soundfile
pip install gfpgan realesrgan
pip install openai-whisper
pip install rembg

# If dlib fails:
brew install cmake
pip install dlib
# Or use: pip install dlib-binary
```

### "FFmpeg not found"?

```bash
# Install FFmpeg
brew install ffmpeg  # macOS
sudo apt-get install ffmpeg  # Ubuntu

# Verify
ffmpeg -version
```

### Out of Memory?

```python
# Use faster preset
preset_name="fast_preview"

# Or reduce resolution
preset.resolution = "1280x720"

# Or disable upscaling
preset.upscale_video = False
```

### Processing Too Slow?

1. Use `fast_preview` preset for testing
2. Reduce script length (< 100 words)
3. Disable face enhancement temporarily
4. Use GPU/MPS if available
5. Close other applications
