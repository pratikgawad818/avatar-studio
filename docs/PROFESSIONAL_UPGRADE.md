## 🔧 Installation & Setup

### 1. System Requirements

**Minimum:**
- macOS 12+ / Ubuntu 20.04+ / Windows 10+
- Python 3.10 or 3.11
- 8GB RAM
- 20GB free disk space
- FFmpeg installed

**Recommended:**
- Apple Silicon (M1/M2/M3) or NVIDIA GPU
- 16GB+ RAM
- 50GB+ free disk space
- SSD for temp files

### 2. Install Dependencies

```bash
# Clone repository (if not already done)
cd avatar-studio

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install basic requirements
pip install -r requirements_pro.txt

# Install F5-TTS (optional, for voice cloning)
pip install git+https://github.com/SWivid/F5-TTS.git

# Download Wav2Lip checkpoint
# Place wav2lip_gan.pth in models/Wav2Lip/checkpoints/
```

### 3. Verify Installation

```bash
# Test imports
python -c "import torch; import cv2; import librosa; print('✓ All imports successful')"

# Check GPU/MPS support
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}'); print(f'MPS: {torch.backends.mps.is_available()}')"

# Verify FFmpeg
ffmpeg -version
ffprobe -version
```

### 4. Run Server

```bash
# Start the server
python app.py

# Or use the run script
./run.sh

# Access web interface
open http://localhost:8002
```

## 🔍 Troubleshooting

### Common Issues:

**1. FFmpeg not found**
```bash
# macOS
brew install ffmpeg

# Ubuntu
sudo apt-get install ffmpeg

# Windows
# Download from ffmpeg.org
```

**2. CUDA/GPU issues**
```bash
# Check PyTorch installation
python -c "import torch; print(torch.cuda.is_available())"

# Reinstall with CUDA support
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

**3. Memory errors**
- Reduce resolution to 720p
- Use "fast_preview" preset
- Close other applications
- Increase swap space

**4. Slow processing**
- Use Apple Silicon MPS or NVIDIA GPU
- Use "fast" voice mode instead of "clone"
- Disable upscaling
- Use lower quality preset

**5. Audio/video out of sync**
- Check FFmpeg version (>= 5.0)
- Ensure audio sample rate is 22050 Hz
- Try re-encoding: `ffmpeg -i input.mp4 -c copy output.mp4`
